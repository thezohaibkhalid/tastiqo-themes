# Archived Liquid themes

The Liquid theme runtime, marketplace, and layout editor were retired in favour of the shared Next.js restaurant website.

All original templates and assets are preserved in Git at `archive/shopify-editor-2026-11-05`. Inspect with `git show archive/shopify-editor-2026-11-05:<path>` or create a separate checkout using `git worktree add ../tastiqo-themes-archive archive/shopify-editor-2026-11-05`.

The active website lives in `../layali-web`; restaurant content is managed in Website Settings in `../tastiqo-front`.
